# UCR Registration Extension

Chrome extension for [UCR class registration search](https://registrationssb.ucr.edu/StudentRegistrationSsb/). It adds GPA, RateMyProfessors, and course-difficulty info under **Course Delivery**, plus a detail modal—only on `registrationssb.ucr.edu`.

[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/baojbphcdchacdilidncmechiklhlbia?utm_source=item-share-cb)
